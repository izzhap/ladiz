# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Software developers using VS Code who want a fast, focused autonomous coding and engineering assistant directly in their editor sidebar.

## Product Purpose

Ladiz AI helps developers build features, fix bugs, refactor code, and write unit tests inside VS Code without leaving their workspace.

## Positioning

A crisp, developer-native coding assistant with subtle, high-craft pixel-style animations and minimal iconography—avoiding generic AI-assistant visual clichés.

## Operating Context

- VS Code sidebar webview (`webview-ui`), narrow vertical viewport (~320px–420px wide).
- Must respect VS Code theme variables (`--vscode-*`) while maintaining a cohesive, intentional visual identity.
- Key surfaces in scope: Welcome / empty state screen and active Task / Chat execution view (header, task card, tool/command blocks, completion card, changed-files summary).

## Capabilities and Constraints

- Minimal icons: strip decorative/redundant icons and rely on typography, spacing, and subtle pixel-art motion.
- Must not look "AI-generated" (no generic gradient-glow blobs, no cliché sparkle/robot tropes, no rainbow-bordered cards).
- Built with React, TypeScript, and Tailwind CSS inside `webview-ui`.

## Brand Commitments

- Name: Ladiz AI
- Differentiator: Crisp pixel-type animation as a signature craft detail.
- Aesthetic constraint: Minimal icons, non-AI-slop, developer-grade restraint.

## Product Principles

1. **Developer-native restraint:** Every pixel in a narrow sidebar must earn its space; typography and alignment carry hierarchy, not decorative icons.
2. **Signature pixel craft:** Use purposeful, crisp pixel-style animation as the memorable brand signature without distracting from code or task output.
3. **Zero AI clichés:** Avoid generic purple/blue glow gradients, sparkle icons, and bloated card chrome.
